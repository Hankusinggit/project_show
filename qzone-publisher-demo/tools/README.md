# 截图分析工具链

开发期用于从真机截图量化提取设计参数（布局、边界、尺寸、色值、文字坐标），产出直接驱动 `../index.html` 的 UI 还原决策，形成「截图 → 量化参数 → 代码」的可复现流程。

## analyze.js —— 布局与色彩分析

依赖 [sharp](https://sharp.pixelplumbing.com/)：

```bash
npm install
node analyze.js <模式> <图片> [参数]
```

| 模式 | 用途 |
|---|---|
| `grid <图> [列数]` | 全图降采样为字符色块图，看整体布局 |
| `cgrid <图> <x> <y> <w> <h> [列]` | 区域放大色块图，看元素细节 |
| `vline <图> <x> <y1> <y2> <step>` | 垂直色彩剖面，精确定位上下边界与元素高度 |
| `hline <图> <y> <x1> <x2> <step>` | 水平色彩剖面，精确定位左右边界与元素宽度 |
| `sample <图> <x> <y> <w> <h>` | 区域取色：平均色 / 最饱和色 / 最深色 |
| `colors <图>` | 全图主色统计（灰阶 + 彩色） |

坐标均为**百分比**，跨分辨率通用。字符图例：

```
. 纯白   : 浅灰   - 亮灰   + 中灰   x 深灰   # 近黑
B 亮蓝   b 深蓝   Y 黄/橙  R 红/粉  G 绿    C 青    P 紫
```

## ocr.jxa —— 文字识别与定位（macOS）

```bash
osascript -l JavaScript ocr.jxa <图片>
```

调用 macOS Vision 框架，输出每行文字的归一化位置：

```
y=12.3% x=15.2% | 这一刻的想法…
```

注意：部分 macOS 版本的中文识别语言模型不可用，届时可用于拉丁文字识别与元素坐标测量。
