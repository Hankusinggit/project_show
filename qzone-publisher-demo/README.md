# QQ空间发布器 · 高保真交互演示

> 从好友动态页点进发布器，编辑图文、@好友、插话题、选可见范围，点「发表」——新说说立刻出现在信息流顶部。一个零依赖、双击即开的产品闭环复刻。

## 运行

无构建、无依赖、无服务器，任意现代浏览器打开即可：

```bash
open index.html   # macOS；Windows 直接双击或拖入浏览器
```

建议用手机模式体验（开发者工具 → 设备模拟），页面按 460px 移动列宽自适应。

## 交互全景

### 动态页
- 好友说说信息流：头像 / 昵称 / 时间 / 配图九宫格 / 位置
- 点赞点亮与计数（事件委托渲染）
- 两个发布入口：顶部 ➕ 与「分享这一刻的想法…」胶囊

### 发布器（按真机截图逐项对齐）

| 功能 | 实现 |
|---|---|
| 富文本输入 | `contenteditable`，自动增高，占位符「这一刻的想法…」 |
| @好友 / 话题标签 | 光标处插入 `contenteditable=false` 的蓝色高亮标签，Selection API 保持光标 |
| 表情面板 | 底部滑出，插入至光标处，支持连续插入 |
| 谁可以看 | 四档可见范围，底部弹层单选，结果回显卡片行 |
| 添加地点 | 位置列表选择，快捷入口即时变色回显 |
| 图片 | 真实选图 → canvas 压缩（≤900px / JPEG 0.75）→ 九宫格预览 / 删除 |
| 发表设置 | 开关式底部弹层 |
| 同步入口 | 个性签名 / 朋友圈，深色圆钮选中态 |
| 草稿 | 输入防抖保存，重进自动恢复（对应真实产品的 saveDraft / restoreDraft） |

### 发表联动
「发表」→ 发布中动效 → 滑回动态页 → 说说置顶出现；localStorage 持久化（刷新不丢），底部「重置演示数据」一键还原。

## 工程亮点

1. **单文件零依赖** —— HTML/CSS/JS 全部内联，分享、托管、嵌入零成本
2. **数据与视图分离** —— 好友 / 话题 / 地点 / 预置说说集中在代码顶部 `DATA` 区，换内容不动逻辑
3. **截图驱动的视觉还原** —— 不靠目测：用 `tools/` 工具链从真机截图提取布局色块图、垂直/水平色彩剖面、精确色值与文字坐标，再按实测数据落样式（如发表按钮渐变 `#2CAAF5→#0098FA`、页面底色 `#F4F3F8`、卡片边距 16px）
4. **富文本细节** —— 粘贴强制纯文本、空态占位伪元素、emoji 与标签混合插入的光标管理
5. **健壮性** —— localStorage 全量 try/catch 降级；图片先压缩再持久化，控制存储体积
